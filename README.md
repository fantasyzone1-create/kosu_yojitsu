# 工数予実管理表

開発メンバーの週単位の工数(予定・実績)を月別シートで管理する Excel テンプレートです。
月シートの追加と、SharePoint 上の工数週報からの実績取込を VBA マクロで行います。

## 主な機能

- **月別シート**: 「YY年MM月」(例: `26年11月`)のシートに、メンバーごとの週単位の予定・実績・差異を記入します。
  - 週は月曜始まりで、月の境界で区切ります。
  - 1 シートに最大 12 名分のブロックと、全体合計のブロックがあります。
- **定時工数・稼働日数**: 月シートの 3~5 行目に次の欄があります。
  - `B3`: 1 日の定時工数(h)の入力欄(初期値 7.5)。
  - 4 行目: 週ごとの稼働日数(日本の平日から祝日を除いた日数)。
  - 5 行目: 週ごとの定時予定工数(稼働日数 × `B3`)。予定欄に入力するときの目安です。
  - 祝日は「祝日」シート(2025~2035 年)を参照します。年末年始などの会社休業日や 2036 年以降は、末尾に追記してください(A2:A400 が対象)。
- **シート追加**: 「シート追加」シートに年・月を入力してボタンを押すと、月シートを追加します。
  - 重複する年月や不正な年月はエラーになります。
- **実績取込**: 「実績取込」シートで指定した週報ファイルから、各メンバーの実績工数を集計して月シートの実績欄に書き込みます。
  - 対象メンバーは、月シートに記載済みのメンバーです。
  - 週報のシートは年度単位(4 月始まり、`YYYY年度`)です。
  - セル内の「期間」と「工数計」を読み取ります。
  - 同じ期間が複数列にある場合は、0 以外で一番右の値を採用します(すべて 0 の場合のみ 0)。
  - 実績欄を上書きする前に、確認ダイアログを表示します。
  - 取込結果の詳細は「実績取込」シートに出力します。
- **条件付き書式**: 実績が予定より小さい場合、実績と差異を太赤字で表示します。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `工数予実管理表.xlsm` | マクロ入りテンプレート(そのまま使えます) |
| `src/create_template.py` | テンプレート(xlsx)を生成する Python スクリプト |
| `src/vba/AddMonthSheet.utf8.bas` | VBA ソース(UTF-8、編集用) |
| `src/vba/MonthSheetTools.bas` | Excel にインポートする VBA(Shift-JIS・CRLF) |
| `.gitattributes` | VBA と Excel を改行・文字コード変換の対象外にする設定 |

## 使い方

### 月シートの追加

1. `工数予実管理表.xlsm` を開き、マクロを有効にします。
2. 「シート追加」シートに年と月を入力します。
3. ボタンを押します。

### 実績の取込

1. 「実績取込」シートの `C4` に、週報ファイルの場所を入力します。
   - SharePoint の場合は、Excel で対象ファイルを開き、「ファイル → 情報 → パスをコピー」で得た直接 URL を使います。
   - ブラウザのアドレスバーにある `Doc.aspx` などの表示用 URL は使えません。
   - `C4` を空にしてボタンを押すと、ファイル選択ダイアログが開きます。
2. 取込ボタンを押し、確認ダイアログで上書きを許可します。
3. 結果は「実績取込」シートの `B10` 以降で確認します。

## 開発

Python 3.9 と uv を使います。パスに日本語が含まれる環境では `PYTHONUTF8=1` を設定してください。

```powershell
$env:PYTHONUTF8 = "1"
uv sync
uv run python src/create_template.py [YYYY] [M] [出力ファイル]
```

`.xlsx` を生成した後、VBA を含めた `.xlsm` にするには、Excel の
「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」を有効にして
`MonthSheetTools.bas` をインポートします。

### VBA を変更するとき

1. `src/vba/AddMonthSheet.utf8.bas` を編集します。
2. Shift-JIS(cp932)・CRLF に変換して `src/vba/MonthSheetTools.bas` を再生成します。
3. 既存モジュール(`MonthSheetTools`)を削除してから、再生成した `.bas` をインポートします。
4. `SetupButton` を実行してボタンを再設定します。
   - 祝日シートの作成と、定時工数欄のない既存の月シートへの追加も同時に行われます(何度実行しても同じ結果です)。
