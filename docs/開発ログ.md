# 開発ログ

Claude Code との開発のやり取りを時系列でまとめたものです(会話の逐語録ではなく要約)。
このリポジトリは Public のため、客先の URL・実データ・個人のメールアドレスは記載しません。

## 1. テンプレート作成

- 依頼: 開発メンバーの工数予実管理表を Excel で作る。シート名は「YY年MM月」、月内のメンバー別・週単位の予定/実績を記入する。
- 実装: `src/create_template.py`(openpyxl)で生成する。
  - 週は月曜始まりで、月の境界で区切る。
  - メンバーごとに「予定」「実績」「差異」の 3 行を持ち、最大 12 名と全体合計を置く。
- 環境の注意: プロジェクトのパスに日本語が含まれるため、uv の editable install が失敗する。`[tool.uv] package = false` と `PYTHONUTF8=1` で回避した。

## 2. 月シートの追加機能

- 依頼: 月ごとのシート追加 → 「シート追加」シートに年月を入力してボタンで追加。
- ボタンにマクロが必要なため、`.xlsm` 形式にした。VBA は `src/vba/` に置く。
  - 編集用は UTF-8 の `AddMonthSheet.utf8.bas`。
  - Excel に取り込む用は Shift-JIS・CRLF の `MonthSheetTools.bas`(編集のたびに再生成する)。
- Excel の「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」を有効にし、PowerShell の COM 自動化で動作確認した。
- 追加時は、年月順にシートを並べ、直近の月シートからメンバー名を引き継ぐ。重複する年月や範囲外の年月はエラーにする。

## 3. 実績取込(SharePoint 上の週報から集計)

- 依頼: 週報 xlsx(年度単位のシート、4 月始まり)から、テンプレートに記載済みのメンバーの実績工数を集計して実績欄へ書き込む。
  - 上書き前に確認ダイアログを出す。
  - OneDrive 同期はできないため、URL またはファイル選択で開く。
- 仕様:
  - セル内の複数行テキストから「期間」と「工数計」を正規表現で読み取る。
  - 同じ期間が複数列にある場合は、0 以外で一番右の値を採用する(すべて 0 の場合のみ 0)。
  - 取込結果は「実績取込」シートに出力する(MsgBox は約 1000 文字で切れるため)。

### つまずいた点と原因

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| VBA のコンパイルエラー | モジュールレベルの `Private` 宣言がプロシージャの後にあった | 宣言をモジュール先頭へ移動 |
| 「年度シートなし」 | SharePoint の表示用 URL(`Doc.aspx`)はブックとして開けない | URL を検出してガイダンスを表示。直接 URL かファイル選択を使う |
| 書き込み 0 セル・期間 0 件 | 「期間」と日付の間の非数字が正規表現の許容より多かった | 許容文字数を `{0,20}` に拡大。実データの最長セルで検証 |
| 単一列で型が合わない | 1 セルの `Range.Value` はスカラーになる | 1 列余分に読んで配列にする |

## 4. 条件付き書式

- 依頼: 実績が予定より小さい場合は太赤字で表示する。
- 実装: 実績行は「実績 < 予定」、差異行は「差異 < 0」で太赤字にする(全体合計も対象)。実績が未入力のセルは対象外。
- 注意: 条件式の相対参照は選択セルが基準になるため、範囲の先頭セルを選択してから追加する。

## 7. 1 日の定時工数・稼働日数・定時予定工数

- 依頼: 1 日の定時工数の入力欄を追加し、稼働日を日本の平日とした場合の予定工数を入力できるようにする。
- 設計判断:
  - 既存の行位置(ヘッダー 6 行目、メンバーブロック 7 行目〜)を変えないため、空いていた 3〜5 行目を使う。取込処理と既存シートへの影響を避けた。
  - 予定欄は手入力のまま、目安として定時予定工数の行を表示する。
  - 稼働日数は `NETWORKDAYS` で数え、祝日は「祝日」シート(範囲名 `祝日リスト`)を参照する。
- 実装:
  - `B3`: 1 日の定時工数(初期値 7.5、0〜24 の数値のみ)。
  - 4 行目: 週ごとの稼働日数(月の境界で区切った週の平日から祝日を除く)。
  - 5 行目: 定時予定工数(稼働日数 × `B3`)。
  - 祝日データは Python の `holidays` パッケージで生成した 2025〜2035 年分。
  - `SetupButton` が、祝日シートの作成と既存の月シートへの欄追加も行う(何度実行しても同じ結果)。
- 検証: 26年11月は稼働日数 0・4・5・5・4・1(計 19 日)、26年12月は計 23 日、27年1月は計 19 日、26年5月は計 18 日で、祝日・振替休日を正しく除外できた。
